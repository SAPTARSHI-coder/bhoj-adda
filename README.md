# Bhoj Adda (ভোজ আড্ডা) — Premium Digital Dining & Direct Conversion Platform
> **Concept Demo & Restaurant Business Value Showcase**
> *Heritage Bengali Dining • Park Street Flagship & Salt Lake Skyline*

A mobile-first digital dining platform and restaurant growth cockpit engineered for **Bhoj Adda**, demonstrating how an independent fine-dining restaurant converts social media traffic (Instagram reels, Facebook food bloggers, Google Search) directly into profitable table bookings and repeat guests—**eliminating 25% to 28% third-party aggregator commissions**.

---

## 🌟 Executive Overview: Why This Platform Exists

Third-party food delivery aggregators (Swiggy, Zomato, EazyDiner) mask guest phone numbers and charge up to 28% in commissions. **Bhoj Adda Direct Platform** demonstrates how the restaurant can:

1. **Own the Diner Funnel**: Convert Instagram & Facebook reel views directly into confirmed bookings.
2. **Eliminate Table No-Shows**: Collect an advance table guarantee deposit (₹500 fully deductible upon arrival).
3. **Build an Owned Customer CRM**: Capture 100% of guest names, verified WhatsApp numbers, birthdays, and anniversaries.
4. **Drive Direct Retention**: Reward diners with Bhoj Coins and automated birthday celebration passes.

## ✨ Features & Customer Journey

### 1. Luxury Bengali Dining Landing Page
- **Visual Aesthetic**: Deep Bengal Terracotta (`#992B15`), Royal Gold (`#D49B37`), Midnight Slate (`#0A0D12`), and Warm Cream (`#FCFAF7`).
- **Hero Dish Showcase**: Rotating carousel of Kolkata signatures (*Dakkhini Daab Chingri*, *Royal Padma Shorshe Ilish*, *Kolkata Kosha Mangsho*, *Awadhi Mutton Biryani*).
- **Direct Value Strip**: 3 clear value pillars (Flat 15% off with code `BHOJADDA15`, zero weekend queues, and complimentary Gondhoraj Ghol).
- **The Spirit of Adda**: 19th-century Zamindari heritage narrative, Ayurvedic 6-rasa philosophy, and traditional Kansa (Bell Metal) dining.

### 2. Interactive Digital Menu & Pre-Order Basket
- **6 Categories**: Bengali Specials, Royal Seafood, Charcoal Kebabs, Main Course & Biryani, Artisanal Desserts, and Heritage Beverages.
- Real-time search, dietary filters (Veg, Non-Veg, Seafood, Chef Signature), and spice meters (Mild, Medium, Kolkata Fiery).
- Sliding cart drawer with 1-click **WhatsApp order generation** and aggregator savings calculator.

### 3. Multi-Step Table Reservation Engine
- **Step 1**: Branch selection (*Park Street Flagship* vs *Salt Lake Skyline*) & Seating Ambience (*Royal Baithak*, *Window Terrace*, *Family Hall*, *Private Chamber*).
- **Step 2**: Dynamic calendar with min-date protection, lunch/dinner service switcher, and real-time slot availability.
- **Step 3**: Party size (1-16 guests), celebration occasion, and dietary notes.
- **Step 4**: VIP Table Guarantee (₹500 deposit) vs Standard Walk-in.

### 4. Razorpay Gateway Simulation & Digital Boarding Pass
- Authentic UPI QR, Cards, NetBanking checkout modal with confetti celebration.
- Boarding pass-style digital VIP ticket with dynamic QR code for reception host scanning, calendar sync, and WhatsApp share.

### 5. Loyalty & Customer Retention Engine
- **Bhoj Coins Wallet**: Earn 10 coins per ₹100 spent directly; instant redemption for sweets and dining vouchers.
- **Birthday & Anniversary VIP Registry**: Automated pass generation (`BHOJ-BDAY-XXX`) granting 20% off and complimentary Baked Rosogolla.

### 6. Restaurant Owner Admin Cockpit
- **Live Floor Plan Matrix**: Interactive status toggles for Tables 1–12 (Available, Reserved, Occupied).
- **Reservation Queue**: Real-time guest seating, bill completion, and 1-click WhatsApp host reminder sender.
- **Live Inventory Manager**: Real-time *In Stock / Sold Out* switch and price modifiers (+/- ₹20).
- **Illustrative ROI Calculator**: Interactive slider showing annual commission savings (e.g. ₹30+ Lakhs on 650 monthly direct orders).

## 🛠️ Technology Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict type-checking)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State Management**: React Context (`RestaurantContext.tsx`)
- **Animation & Effects**: [Framer Motion](https://www.framer.com/motion/) & [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Fonts**: Playfair Display (Serif) & Plus Jakarta Sans (Sans-serif)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm, yarn, or pnpm

### Installation

```bash
# 1. Clone the repository
git clone <repository-url>
cd demo

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Build optimized static bundle
npm run build

# Start production server
npm run start
```
